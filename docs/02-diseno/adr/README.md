# Registro de decisiones arquitectónicas (ADR)

Cada decisión arquitectónica relevante se documenta en un archivo propio con el formato
`NNNN-titulo-en-minusculas.md`, usando esta plantilla:

```markdown
# ADR-NNNN: <título>

- Estado: propuesta | aceptada | reemplazada por ADR-MMMM
- Fecha: dd/mm/aaaa
- Decide: <integrantes>

## Contexto
Qué problema o restricción obliga a decidir.

## Alternativas consideradas
Opciones evaluadas y por qué se descartaron.

## Decisión
Qué se decidió, en una frase.

## Consecuencias
Qué se gana, qué se pierde y qué queda condicionado por esta decisión.
```

Las decisiones ADR-01 a ADR-07 están consolidadas en el Documento de Arquitectura
Conceptual y Mecánicas del Videojuego, sección 2.9.
